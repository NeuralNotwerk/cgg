integration branch and compared, `(id, language)` pair by pair, with the
0.13.4 table that parts 1–4 describe (`git show 00564f9d:…/rules.rs`).
`SPECS` now holds 852 `RuleSpec`s with 653 distinct ids
over 38 languages (0.13.4: 507, 390, 36).
This part lists the 345 pairs added since 0.13.4 and the 18
pairs whose fields changed; 0 pairs were removed. Parts 1–4
are otherwise unchanged and still describe every other row.

Columns are those of parts 1–4. Triggers are copied from the source; a
`<NAME>` value is a named constant. The benchmark-app column is read from
`APPS` in `scripts/benchmark.sh` (first four apps; `~` = detected, gap
only) or says `APPS_UNVERIFIED`. Kind `Tool` (new in 0.14.0) is a callable
an LLM host invokes with arguments the model chose; it counts as untrusted
input and its entry is routed by the tool's name.

Matching semantics added in 0.14.0 that these rows rely on (all in
`crates/cgg-resolve/src/frameworks/mod.rs` unless stated):

- **Per-file evidence** (`rules::FILE_SCOPED_EVIDENCE`: python,
  javascript, typescript, java, kotlin, go, rust, swift;
  `rules::IMPORT_SCOPED_ATTRIBUTES` adds python, javascript, typescript):
  a bare registrar, a base type and (import-scoped languages) an attribute
  count only in a file that carries the rule's evidence. Implicitly
  imported names (`cgg_core::stdlib::IMPLICIT_IMPORTS`) carry it
  everywhere; test-kind rules are exempt.
- **Patterns:** `prefix*suffix` infix name patterns
  (`name_pattern_matches`); name patterns in `base_types` against the
  written name and its last segment; `$.$Suffix` nested bases
  (`nested_base_matches`); a `*` in `detect` matches an import segment
  (`import_segments`); `owner.name` methods (`owner_qualified_matches`).
- **Registrar slots:** `Verb:slot` takes only values passed under that
  keyword, option key or label (`cgg_core::frameworks::split_registrar_slot`).
- **Side tables** in `rules.rs`: `CONSTRUCTOR_METHOD` (`<init>`),
  `parameter_types_for`, `path_route_dir`, `method_paths_for`,
  `public_members_are_entries`, `methods_are_free_functions`,
  `base_types_need_harness_file`, `container_member_skipped`,
  `registrars_need_file_evidence`, `LEXICAL_CONSTANT_LANGS`,
  `MemberSource::named`, and the case-sensitive list
  `methods_case_sensitive` (every Go rule included).
