Call graph generator — point at folders, get a graph.

Usage: cgg [OPTIONS] <PATH>...

Arguments:
  <PATH>...
          One or more source directories or files to analyze

Options:
  -o, --output <FILE>
          Write output to FILE instead of stdout. Use `-` for stdout

  -t, --type <FORMAT>
          Output format
          
          [default: mermaid]
          [possible values: mermaid, json, dot, graphml]

      --filter <PATTERN>
          Filter callables by pattern. Repeatable. Regex by default; prefix with `glob:` to use glob
          syntax. Matched against fully-qualified names

  -n, --hops <N>
          Neighborhood depth around each `--filter` match. `-n 0` enumerates full entry-to-exit call
          paths passing through matches
          
          [default: -1]

      --max-paths <N>
          Cap per-match path count in `-n 0` mode. Overflow is recorded in the audit log
          
          [default: 1000]

      --include-tests
          Include `tests/`, `__tests__/`, `*_test.go`, etc. By default test-looking files are
          analyzed but tagged — this flag is a reserved future knob; honored as a no-op in v1

      --ignore-file <PATH>
          Path to an additional ignore file (gitignore syntax)

      --jobs <N>
          Number of parallel jobs. `0` means "auto" (rayon default)
          
          [default: 0]

      --cache <DIR>
          Cache directory. Default: `./.cgg-cache`

      --no-cache
          Disable reading and writing the on-disk cache

      --lang <LIST>
          Restrict analysis to the given comma-separated language ids. Example: `--lang rust,python`

      --audit-format <AUDIT_FORMAT>
          Shape of the audit output. `json` = batched doc; `jsonl` = streamed events (one per line,
          SIEM-friendly)

          Possible values:
          - json:  Single JSON document (pretty)
          - jsonl: One JSON object per line
          
          [default: json]

      --metrics <FILE>
          Force a sidecar metrics file. Useful when `-t json` already embeds the audit but an
          external tool wants a split file

  -v, --verbose...
          Increase verbosity. Repeat: `-v`, `-vv`

  -q, --quiet
          Silence everything except errors

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version
